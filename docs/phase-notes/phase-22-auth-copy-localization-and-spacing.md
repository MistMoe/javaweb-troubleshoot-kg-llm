# 阶段 22：登录注册页中文化与轻量间距调整

## 本阶段目标

在保留既有登录注册页背景图、四分区结构、字体和业务逻辑的前提下，将主要交互文案调整为中文，并略微放松表单区的排版节奏。

## 完成内容

- 登录页标题改为“欢迎回来”，主次按钮改为“登录系统 / 创建账户”。
- 注册页标题改为“创建账户”，主次按钮改为“完成注册 / 返回登录”。
- 用户名、显示名称、邮箱、密码等字段标签统一为中文。
- 副标题、说明文字与右下角工作空间入口统一为中文。
- 保留英文系统名 `JavaWeb Troubleshoot KG LLM` 和 `AI / KG / DB / API` 能力缩写，形成有意的中英层级。
- 将标题区、表单行、字段标签和按钮组的间距各增加少量像素，让内容更舒展。

## 未改动内容

- 未修改登录或注册业务逻辑。
- 未修改背景图、四分布局、卡片尺寸、标题字体和按钮材质。
- 未修改登录后的系统页面。

## 后续衔接

整体界面改版继续沿用登录注册页的浅蓝灰、冷白、深色文字和克制蓝色点缀。下一步先确定登录后页面的统一设计令牌、公共面板结构和 ECharts 主题，再按页面逐步实施。
