# 故障知识库浮雕界面优化计划

## 目标

保留故障知识库现有的大区块布局、接口、角色权限、投稿审核、收藏、增删改和 Neo4j 同步逻辑，仅优化区块内部层级与视觉材质。

## 实施步骤

1. 为知识库主要卡片、案例行和详情区增加页面专属类名，避免 `.filter-card`、`.detail-card` 等全局样式污染。
2. 沿用系统级 `surface-card`、`inset-well`、`metric-plate` 和 `action-button`，移除大面积渐变及彩色整边。
3. 保留头部加三项统计、左侧筛选与案例列表、右侧案例详情的现有排布，适当增加区块间距和内容留白。
4. 调整案例行、标签、收藏、维护按钮和投稿审核区的层级，让普通用户与维护角色的操作更容易区分。
5. 保留组件分布 ECharts，将实例改为 `shallowRef`，统一冷白图表主题并保证容器尺寸稳定。
6. 运行 UI 契约检查和 Vite 生产构建，记录结果并补充阶段文档。

## 不修改

- 登录与注册页
- 故障知识库接口和请求参数
- ADMIN / MAINTAINER 审核、维护权限
- USER 浏览与收藏权限
- 投稿生成、审核、写入知识库流程
- Neo4j 同步逻辑
