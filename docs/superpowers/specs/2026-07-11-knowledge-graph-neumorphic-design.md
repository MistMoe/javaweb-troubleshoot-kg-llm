# 分析历史高度统一与知识图谱浮雕设计

## 分析历史

- 标题卡最小高度由 154px 调整为 204px，与故障知识库和我的收藏标题区对齐。
- 保留标题左侧说明和右侧三项内嵌指标，不改变历史数据与导出功能。

## 知识图谱标题

- 保留左侧标题大卡与右侧节点、关系、类型三张独立统计卡。
- 四张卡统一为 204px 高度、相同冷白浮雕材质与上下边界。
- 三张统计卡分别使用蓝、紫、青数字点色，不使用彩色整边。
- 不将三张统计卡放入标题卡内部。

## 图谱工作区

- 第二行使用全宽控制带，集中放置故障案例、节点搜索、查看关系、搜索节点、刷新案例和从 MySQL 导入图谱。
- “从 MySQL 导入图谱”为蓝色主操作；查看和搜索为普通浮雕操作；刷新为图标操作。
- 第三行左侧为大尺寸关系画布，右侧为节点详情与使用提示。
- 图谱图例保留在画布标题区，画布使用内凹材质，不使用背景渐变。
- ECharts 节点颜色保持蓝、青、紫、绿、黄、珊瑚等小面积区分。

## 技术约束

- 图谱实例使用 `shallowRef`，画布使用页面专属 `kg-graph-canvas` 类。
- 保留 `/api/error/list`、`/api/kg/import`、`/api/kg/graph/{id}`、`/api/kg/search`。
- 保留缩放、拖动、节点点击、活动节点统计和 ResizeObserver。
- 不修改登录注册、导航、AI 助手或角色权限。
