# 登录后系统整体视觉改版设计

## 1. 目标

在不修改登录注册页、不改变后端接口与业务权限逻辑的前提下，将登录后的系统统一改造成“冰晶浮雕数据工作台”。改版需要保留现有浅蓝灰色系，同时增强页面层级、数据可视化与产品辨识度，避免灰扑扑、卡片堆叠和普通后台模板感。

## 2. 范围与边界

### 纳入改版

- 全局 AppShell：顶部栏、侧边导航、主工作区、全局 AI 助手层级。
- 工作台首页。
- 智能排障、分析历史、故障知识库、我的收藏、知识图谱、用户管理、角色设置、个人资料。
- 登录后页面共享的按钮、输入框、筛选器、状态标签、面板、空状态和 ECharts 主题。

### 明确不改

- 登录页与注册页的背景图、布局、字体、材质和业务逻辑。
- Spring Boot、MySQL、Neo4j、DeepSeek 接口契约。
- ADMIN、MAINTAINER、USER 的既有权限规则。
- 现有菜单顺序、页面入口和全局 AI 助手功能。
- 不引入新的 UI 框架或动画库。

## 3. 设计原则

1. 浮雕来自材质体系，不是统一的一圈阴影。
2. 页面底色偏浅蓝，面板表面偏冷白，先依靠明度区分层级。
3. 左上冷白高光、右下蓝灰环境阴影模拟固定光源。
4. 外层工作面板采用凸起材质，图表画布、输入框和进度槽采用内凹材质。
5. 卡片不层层嵌套；卡片内部优先使用留白、细线或内凹区域分组。
6. 页面不使用大面积渐变，不使用霓虹、装饰光球和深色后台风格。
7. 设计感由非均匀网格、比例、留白、仪表刻度和数据铭牌共同形成。
8. 不使用星芒图案作为登录后系统的视觉元素。

## 4. 设计令牌

### 色彩

- 页面底色：`#e5ecf3`
- 次级底色：`#edf3f8`
- 面板表面：`#f6f9fc`
- 强调冷白：`#ffffff`
- 主文字：`#17263d`
- 次文字：`#6f8299`
- 弱文字：`#93a3b5`
- 细线边框：`rgba(139, 164, 191, 0.24)`
- 主操作蓝：`#4f86e8`
- 数据淡紫：`#9689e6`
- 数据湖青：`#62b9ca`
- 数据薄荷绿：`#68b99a`
- 警告珊瑚红：`#dc7378`

颜色分工固定：蓝色用于主操作与核心趋势，紫色用于知识图谱与模型数据，青色用于数据库与连接状态，绿色用于成功和健康状态，珊瑚红只用于失败、危险和异常。

### 圆角与间距

- 普通面板圆角：`8px`
- 输入框、列表条目与小组件圆角：`6px`
- AI 助手与状态胶囊可使用更大圆角。
- 页面区块间距：桌面端 `24px`，窄桌面 `20px`，移动端 `16px`。
- 卡片内部主要间距：`20px` 或 `24px`。
- 标题与说明保持紧凑，内容区之间适度放开。

### 浮雕层级

- Level 0：页面底板，无阴影。
- Level 1：普通功能面板，极浅外凸阴影与冷白高光。
- Level 2：核心图表、关键工作区和主要操作面板，阴影略强但不漂浮。
- Inset：图表画布、搜索框、输入区、进度槽和选中控制使用内阴影。
- Hover：不改变整体位置，仅提升边缘高光、功能色边线或阴影清晰度。
- Active：按钮和切换控件由外凸转为轻微内凹。

禁止使用均匀 `0 0` 环形灰影作为主要浮雕手段。

## 5. 公共界面架构

### AppShell

- 顶部栏压缩高度，保留菜单开关、系统名、当前页面、搜索、通知、用户区和退出。
- 顶部栏使用 Level 1 浮雕，不使用重毛玻璃。
- 侧边导航保持图标式窄栏，当前菜单使用蓝色内凹槽与细边标识。
- 主工作区使用统一最大宽度和 `24px` 页面间距，禁止横向溢出。
- AI 助手继续挂载在 AppShell，使用蓝色实体浮雕胶囊，窗口保持全局高层级。

### 公共组件边界

- `surface-card`：外凸工作面板，只负责材质、边框与基础间距。
- `inset-well`：内凹容器，用于图表、输入和状态轨道。
- `page-heading`：紧凑页头，包含英文小标签、中文标题、说明与右侧状态铭牌。
- `metric-plate`：关键数字、单位、趋势和数据来源。
- `status-chip`：连接、成功、处理中和异常状态。
- `chart-frame`：统一 ECharts 容器、刻度说明、图例与空状态。
- `action-button`：主按钮、次按钮、危险按钮和图标按钮的统一层级。

公共样式通过全局设计令牌与明确的前缀类实现。页面私有 CSS 只处理页面网格和特有组件，避免 `.stat-card` 等无作用域类再次互相覆盖。

## 6. 页面布局设计

### 工作台首页

- 将现有大欢迎面板压缩为紧凑状态页头。
- 第一屏采用非均匀拼贴：左侧主趋势图，中部系统连接状态，右侧模型服务铭牌。
- 第二行放最近分析记录与故障类型分布。
- 首页保留六类信息，但不再将每个数字做成独立卡片。
- 主趋势图使用 ECharts 平滑折线与轻量柱形组合；颜色为蓝、紫、青，不使用渐变填充。

### 智能排障

- 左侧输入与参数区使用外凸面板，日志文本域使用大面积内凹输入井。
- 中间分析结果使用步骤轨道和置信度仪表。
- 右侧证据关系图保持较大画布，使用紫色与蓝色节点。
- PDF/Word 导出作为结果区主操作之一，不改变后端分析流程。

### 分析历史

- 页头压缩，历史数量、命中率和图谱节点合并为一组数据铭牌。
- 左侧历史列表保持平整，只在选中项使用内凹蓝色状态。
- 右侧详情与技术栈分布上下组织，避免面板重叠。
- 技术栈图使用水平条形或环形图，颜色固定为蓝、紫、青、绿。

### 故障知识库

- 页头、搜索筛选、审核入口与知识列表使用清晰的纵向节奏。
- 案例列表为轻浮雕条目，管理员/维护员显示编辑删除，普通用户显示收藏。
- 右侧详情上部放组件分布图，下部放案例正文。
- 组件分布使用 ECharts 横向条形图或点线图，禁止无意义的平滑下降曲线。
- 投稿审核作为独立工作区，不再把列表挤到页面底部。

### 我的收藏

- 页头右侧显示收藏总数、组件覆盖数和常用入口三项紧凑铭牌。
- 收藏列表与详情保持双栏，空状态使用内凹容器。
- 不增加与知识库重复的统计图表。

### 知识图谱

- 图谱画布是页面最大视觉区域，使用内凹材质并保证足够高度。
- 筛选、节点搜索与图例围绕画布布置，不占用过多顶部空间。
- 节点详情使用 Level 1 侧板，颜色与节点类型一致。
- ECharts graph 使用稳定的缩放、拖拽、力导布局和 ResizeObserver。

### 用户管理与角色设置

- 管理页面采用更平整的浮雕：表格外层 Level 1，行内不重复加阴影。
- 筛选器与分页使用内凹控件。
- 角色矩阵使用浅色分区和低饱和状态色，不添加无业务意义的图表。
- 新建、编辑、禁用和删除操作保持清晰的颜色等级。

### 个人资料

- 个人信息、角色权限和使用统计采用非均匀双栏。
- 活跃度使用小型 ECharts 柱状图，蓝紫配色。
- 不修改用户数据接口，只展示已有数据或明确空状态。

## 7. 图表体系

- 继续使用项目已有 Apache ECharts 5.6.0。
- 建立统一主题配置：字体、轴线、分割线、tooltip、图例、颜色与动画时长。
- 图表背景透明，由 `inset-well` 提供材质。
- 单张图表最多使用四种数据色。
- 坐标轴与分割线使用低对比蓝灰，tooltip 使用冷白浮雕面板。
- 数据变化使用 300 至 500 毫秒缓动，不引入复杂动画库。
- 图表必须提供空数据、加载失败与容器尺寸变化处理。

## 8. 数据与错误处理

- 视觉改版不更改请求地址、请求参数和响应结构。
- 接口加载中使用对应面板内的骨架或状态文本，不让页面整体跳动。
- 接口失败时保留页面结构，在原面板内显示错误状态与重试按钮。
- 空列表与空图表使用统一内凹空状态，不展示伪造数据。
- 首页已有演示统计可以保留，但必须在代码中与真实接口数据边界保持清楚。

## 9. 响应式规则

- 大于等于 `1280px`：完整非均匀网格。
- `960px` 至 `1279px`：缩减列数，保持主图优先。
- 小于 `960px`：侧栏与内容适配，双栏转单栏。
- 小于 `720px`：页头操作换行，AI 助手窗口适配视口。
- 所有断点禁止横向滚动，图表容器必须主动 resize。

## 10. 验证与实施顺序

1. 建立全局令牌和公共材质类，不改变页面业务结构。
2. 改造 AppShell，验证导航、Tooltip、AI 助手与滚动层级。
3. 改造首页并建立 ECharts 统一主题，作为视觉基准页。
4. 按智能排障、分析历史、故障知识库、我的收藏、知识图谱、用户管理、角色设置、个人资料的顺序逐页改造。
5. 每完成一页运行前端构建，并在桌面与移动宽度检查溢出、遮挡、图表非空和交互状态。
6. 每个阶段在 `docs/phase-notes` 写入完成内容、验证结果和后续衔接。

## 11. 验收标准

- 登录注册页保持现状。
- 登录后所有页面使用同一材质、色彩、间距和交互语言。
- 页面整体明亮清冷，不灰扑扑、不使用大面积渐变。
- 浮雕具有固定光源方向、外凸与内凹层级，不是统一环形阴影。
- 卡片间距略大于当前版本，但信息密度仍适合工作台。
- 图表颜色清楚，且与对应业务语义一致。
- 页面无横向滚动条，图表、AI 助手和 Tooltip 不被遮挡。
- ADMIN、MAINTAINER、USER 的菜单和操作权限不发生回归。

## 12. 首页实施修订

- 首页采用“舒展型浮雕工作台”，不要求首屏塞下全部模块，允许工作区自然纵向滚动。
- 桌面端卡片间距使用 28px，主卡片内边距使用 30px；图表与状态模块获得独立留白。
- 不使用贯穿整张卡片的彩色顶边。颜色只进入图表、状态圆点、关键数字、图标和操作按钮。
- 首页图表实例使用 Vue `shallowRef` 保存，避免深层响应式代理 ECharts 内部模型。
- 故障类型分布图使用明确的 300px 绘图高度，避免 ECharts 在初始化时获得零高度容器。
